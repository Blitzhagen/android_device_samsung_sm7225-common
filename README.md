# Device configuration for Snapdragon 750G (SM7225) SOC devices
The Qualcomm Snapdragon 750G (SM7225) is a mid-range system-on-a-chip (SoC) for Android devices.

## SoC specifications
Basic        | Spec Sheet
------------:|:----------------------
Lithography  | 8nm
CPU          | Octa-core Kryo 570 (2x 2.2GHz + 6x 1.8GHz)
GPU          | Adreno 619
Architecture | 64bits, ARMv8-A (A32, A64)
L3 cache     | 3 MB
Features     | Snapdragon X52 5G modem, Hexagon 694 DSP, Spectra 355L ISP
